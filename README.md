# My Channels

Repositorio personal para centralizar accesos web a canales en vivo, pensados para abrirse desde Android TV / Google TV usando accesos directos creados con `TV App Repo`.

Cada canal se encuentra en una carpeta independiente y contiene su propio `index.html`.
